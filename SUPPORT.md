# Support

## Getting help

- **Bugs and feature requests** — open an issue in the relevant
  language repository using the issue template.
- **Questions and general discussion** — use
  [GitHub Discussions](https://github.com/orgs/mq-rest-admin-project/discussions)
  on the relevant repository.

## Which repo?

| Topic | Repository |
|---|---|
| Python wrapper (pymqrest) | [mq-rest-admin-python](https://github.com/mq-rest-admin-project/mq-rest-admin-python) |
| Java wrapper | [mq-rest-admin-java](https://github.com/mq-rest-admin-project/mq-rest-admin-java) |
| Go wrapper | [mq-rest-admin-go](https://github.com/mq-rest-admin-project/mq-rest-admin-go) |
| Ruby wrapper | [mq-rest-admin-ruby](https://github.com/mq-rest-admin-project/mq-rest-admin-ruby) |
| Rust wrapper | [mq-rest-admin-rust](https://github.com/mq-rest-admin-project/mq-rest-admin-rust) |
| Shared documentation | [mq-rest-admin-common](https://github.com/mq-rest-admin-project/mq-rest-admin-common) |
| Dockerized MQ test environment | [mq-rest-admin-dev-environment](https://github.com/mq-rest-admin-project/mq-rest-admin-dev-environment) |
| Org-level templates, community health files | [.github](https://github.com/mq-rest-admin-project/.github) |

If you're unsure which repo is relevant, pick the closest match and
the maintainer will route it.

## Expectations

mq-rest-admin is an independent community project, not an IBM product.
There is no SLA-backed support. Issues and discussions are addressed as
time permits. We appreciate your patience.
